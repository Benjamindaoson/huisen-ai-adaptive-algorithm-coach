# 汇森AI 评委运行说明

## 1. 推荐验证方式

初赛优先观看3分19秒Demo视频和方案PDF。需要验证工程时，可按本说明启动本地完整栈。

## 2. 环境要求

- Windows 11、macOS或Linux；
- Node.js 24或更高；
- npm；
- Docker Desktop或兼容Docker Compose环境；
- 至少为Judge0预留可用内存；
- 可选DeepSeek API Key。没有Key时系统必须显示真实降级状态。

## 3. 安装依赖

在仓库根目录运行：

```powershell
npm install
npm --prefix web install
npm --prefix services/runner/gateway install
```

项目使用各目录`package-lock.json`固定依赖版本，不需要安装全局npm包。

## 4. 配置本地后端

复制环境变量模板：

```powershell
Copy-Item services/runner/.env.example services/runner/.env
```

打开`services/runner/.env`，至少设置不重复的PostgreSQL、Redis和Judge0本地秘密。若要体验真实Mentor模型调用，在当前终端设置服务器端Key：

```powershell
$env:DEEPSEEK_API_KEY='由评委自行提供的测试Key'
```

不要给该变量添加`VITE_`前缀，也不要把真实Key提交到仓库。

## 5. 启动完整栈

```powershell
npm run stack:up
```

验证Gateway：

```powershell
Invoke-WebRequest http://127.0.0.1:8787/healthz -UseBasicParsing
```

预期HTTP 200。响应会如实显示Mentor存储、身份和模型状态；本地开发可能显示`permissive-local`，这不是生产认证。

启动Web：

```powershell
npm --prefix web run dev
```

打开终端输出的本地地址。仓库的`web/.env.development`只包含三个`127.0.0.1:8787`公开端点，不包含秘密。

## 6. 主验证路径

1. 打开“今日训练”；
2. 完成AI入门诊断；
3. 在诊断结果中查看实际使用的三条证据和推荐原因；
4. 进入“数组遍历”训练舱；
5. 完成状态预测和局部编码；
6. 进入题目工作台，运行当前草稿，先取得确定性的执行证据；
7. 在Mentor时间线查看工具调用、证据、假设和最小提示；
8. 根据状态预测或最小提示修改代码并重新运行；
9. 查看验证回执、迁移任务和成长回放。

## 7. 技术验证

```powershell
npm test
npm run lint
npm run typecheck
npm run build:web
```

以提交包中的最终检查结果为准。工程回归通过只证明代码在本地可复现，不等于真实学习效果已经验证。

质量门禁：

```powershell
npm run quality:mentor
npm run quality:judge
```

当前预期：Mentor真实教师裁决0/100，门禁非零退出；正式金标题判题包0/754，报告`passed:false`。这是项目主动保留的诚实质量边界。

## 8. 降级与异常

- **DeepSeek未配置或不可用**：界面显示服务不可用或本地静态回退，不能称为真实Agent诊断；
- **Judge0不可用**：代码面板显示运行服务不可用，源码不会在Gateway进程内直接执行；
- **未登录**：学习计划与草稿保存在当前浏览器，可导出/导入；
- **网络中断**：学习事件进入本地outbox，恢复后幂等同步；
- **证据不足**：Mentor说明还缺什么，不直接给确定性结论。

## 9. 数据清理

- 浏览器数据可在“信任与数据”页面导出或清除；
- 登录模式可请求服务端导出和删除；
- 比赛演示请使用独立浏览器档案，不导入真实用户学习记录。

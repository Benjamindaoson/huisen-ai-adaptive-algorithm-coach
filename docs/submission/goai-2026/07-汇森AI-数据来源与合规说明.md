# 汇森AI 数据来源与合规说明

## 1. 教育边界

汇森AI提供个性化学习规划、编程过程辅导、错因分析、同类训练和学习成长回放，属于形成性学习支持工具。系统输出不替代教师教学判断、学校评价、正式考试结果、企业招聘结论或其他专业机构的最终评价。

产品不承诺就业结果，也不把课程完成、查看答案或AI建议直接认定为能力掌握。

## 2. 数据分类

| 类别 | 示例 | 使用方式 | 比赛展示规则 |
|---|---|---|---|
| 团队自建内容 | 数组遍历微课、预测题、模拟错误代码、教学策略 | 教学和Demo | 可展示，并标注“自建/模拟” |
| 公开许可内容 | 开源软件文档、许可清晰的算法素材 | 知识与技术实现 | 记录来源、版本和许可证 |
| 模拟学习数据 | 比赛专用诊断选择、运行事件、迁移事件 | 验证个性化流程 | 明确为模拟，不称真实用户效果 |
| 用户本地数据 | 代码草稿、运行结果、学习事件 | 当前浏览器学习与可选同步 | 最小化收集，可导出、删除 |
| 待确认来源内容 | 来源或授权尚未完成分级的题目 | 内部整理与待审核 | 不进入核心PPT、视频和一页纸 |

“754道”只表示当前建立了754道算法与编程练习的结构化索引，不表示全部内容已经完成来源审核、人审金标或生产级隐藏判题。

## 3. 学习数据最小化

- 长期学习事件只记录教学必要的语义动作，如诊断选择、提交、提示、迁移和复测；
- 不同步普通按键、鼠标轨迹等无意义噪声；
- 学习事件不保存完整源码和任意标准输入输出正文；
- 每个数字孪生更新必须包含事件类型和证据引用；
- 模型不能直接修改掌握度或生成心理画像；
- 浏览器本地数据支持JSON导出、导入和清除；
- 登录用户可以请求服务端导出和删除学习数据。

## 4. 身份、权限与密钥

- DeepSeek API Key、Mentor签名秘密和数据库凭据只存放在Gateway环境变量；
- 任何以`VITE_`开头的变量都会进入浏览器，因此不得包含秘密；
- 当前比赛本地环境如实显示`permissive-local`身份模式，不描述为生产认证；
- 生产环境必须使用HTTPS、安全Cookie、强随机签名秘密、身份投递服务和PostgreSQL；缺失关键配置时Gateway拒绝以生产模式启动；
- Mentor和学习记录请求按学习者主体校验，不允许客户端读取他人会话。

## 5. AI与判题边界

- Judge0或确定性测试决定编译、运行和通过状态；
- 模型只能形成诊断假设、教学问题和最小提示，不能改变判题结果；
- Hidden tests、参考源码和服务器内部Oracle不会返回浏览器；
- 模型生成的测试、解释或反例默认属于候选证据；
- 只有人工评审或不同语言参考解执行共识才能提升预期输出可信等级；
- 模型失败、响应不合规或证据不足时，系统显示拒绝、未验证或降级状态。

## 6. 第三方服务与依赖

| 依赖 | 用途 | 风险与替代 |
|---|---|---|
| DeepSeek API | Mentor工具选择、重规划与教学语言生成 | 商业API、按量计费；可替换为其他兼容Provider或确定性降级 |
| Judge0 CE | 四语言不可信代码隔离执行 | 需要独立计算资源和安全运维；不可依赖公共实例作为生产SLA |
| Tree-sitter及语言语法包 | 多语言语法树 | 仅作为结构证据，不宣称完整语义正确性 |
| React、Vite、Fastify、Monaco | Web应用与Gateway | 版本由仓库锁文件固定，遵守各自开源许可 |
| PostgreSQL、Redis | 权威学习数据、提交和运行队列 | 生产需要备份、访问控制、监控和恢复演练 |

第三方具体版本记录在`package-lock.json`、`web/package-lock.json`、`services/runner/gateway/package-lock.json`和Docker Compose镜像标签中。正式开源或交付时继续核对上游许可证和NOTICE要求。

## 7. 比赛数据说明

- Demo使用团队自建“数组遍历”微课和有界模拟学习事件；
- 演示中的错误代码由团队为教学场景自行构造；
- 产品截图不展示个人身份、邮箱、手机号、密钥或未脱敏学习历史；
- 不使用真实未成年人数据；
- 不把模拟学习结果表述为真实用户实验；
- 比赛手册只作为规则依据，不复制其设计模板或大段内容。

## 8. 已知限制与后续工作

- 正式Mentor教师裁决案例目前为0/100；
- 正式金标题判题包覆盖为0/754；
- 题目来源和授权仍需逐项分级；
- 当前本地身份为宽松模式；
- 尚未获得真实学习者迁移通过率、7日复训率和就业结果。

后续将优先完成内容来源审核、真实教师盲评、迁移与延迟复测实验、生产身份、备份恢复和三网访问验证。

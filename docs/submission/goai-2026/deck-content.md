# 汇森AI｜GOAI 初赛路演内容

## 01｜你缺的不是更多答案，而是一次真正学会的过程

**汇森AI**

AI+教育｜面向个性化学习与教学辅助的教育 Agent

> 不是替学生做出这道题，而是让他独立做出下一道题。

个性化算法学习·职业教育 / 编程教育·可运行 Web App

## 02｜最难的不是听懂算法，是离开课程后仍然不会开始

**目标用户**

非科班、基础薄弱，或已经学过课程却仍然不会独立做题的算法学习者。

**三个反复发生的断点**

1. 课程讲完了，但不知道当前这题应该从哪里开始。
2. 参考答案看懂了，换一个题面又不会。
3. 练了很久，却没有人说清究竟卡在理解、建模、实现还是调试。

## 03｜汇森AI把学习变成一条会根据你而改变的路

**诊断**：从目标、基础、练习表现和时间判断今天先解决什么。

**教学**：用通俗讲解和程序状态展示补上当前最小的先修知识。

**练习**：先预测，再动手，只修改最关键的一段代码。

**验证**：根据真实运行结果给出最小提示，修改后自动重测。

**迁移**：换一个表面不同、技能相同的任务，确认能力是自己的。

## 04｜第一分钟，AI先弄清你为什么卡住

### 个性化学习规划 Agent

根据学生目标、知识基础、练习表现和学习时间，生成阶段性学习计划，并动态调整学习路径。

界面当场告诉用户：AI看到了哪些证据；当前最可能卡在哪一步；为什么今天先练这个；哪些事还缺少证据，不能现在下结论。

## 05｜十分钟，把一个抽象算法变成五个可完成动作

### 作业辅导 Agent

**听懂**：用生活语言讲清直觉。

**看见**：把数组、指针和变量状态画出来。

**预测**：运行前先说下一步会发生什么。

**动手**：只补当前最关键的一小段代码。

**迁移**：立即进入不同题面的同技能任务。

分步骤提示、错因分析、知识点回顾和同类题训练，而非直接给出答案。

## 06｜Mentor不抢答，它先取证，再决定下一步

1. **任务理解**：读取学习目标、当前任务、代码、运行结果和学习记录。
2. **流程编排**：决定先追问、执行代码、检索知识还是生成测试。
3. **工具调用**：调用受限代码执行、Tree-sitter、数据流分析、测试和学习证据查询。
4. **知识增强**：检索算法知识、典型错误和分级可信内容。
5. **多轮交互**：预测、运行、追问、修改、再验证。
6. **结果交付**：学情分析报告、改进建议和唯一下一步任务。

DeepSeek 不可用或证据不足时，系统显示真实降级或继续取证，不把规则文本伪装成模型结论。

## 07｜每一次反馈，都要能回答“你到底学会了什么”

### 学情诊断 Agent

基于练习记录、测试结果和模拟学习数据，识别知识薄弱点，生成学情分析报告和改进建议。

系统分开记录：任务是否通过；学生使用了多少帮助；能否解释自己的修改；换一个任务后能否独立完成；1、7、30 天后是否仍然记得。

模型不能凭感觉改写掌握度，学习状态只由可解释事件投影更新。

## 08｜能换一道题独立完成，才算真正会了

一道题通过，只能证明这次完成了。汇森AI会立即安排表面不同、技能相同的迁移题；不带提示和参考答案进行独立验证；在遗忘可能发生时安排延迟复测。

**成长回放告诉学生**：我为什么今天练这个、刚刚学会了什么、哪里还不稳、下一步为什么这样安排。

## 09｜学习不能停在题库，能力最终要进入真实工作

### 职业教育 / 编程教育 Agent

围绕岗位技能、项目实训、代码练习和面试准备，提供任务拆解、过程指导、反馈评价和学习路线建议。

项目实训要求学习者：读需求 → 理解代码仓库 → 定位缺陷 → 制定计划 → 修改代码 → 运行测试 → 工程复盘。

当前使用公开或模拟项目数据，不把模拟结果冒充企业录用结论。

## 10｜从个人过桥训练切入，再连接学校和企业

**个人学习**：免费完成起步微课和基础练习；个性化学习规划、Mentor辅导、迁移复测和项目反馈形成订阅价值。

**学校 / 培训机构**：AI承担重复辅导，向教师交付学情分析、课程大纲、课堂活动、案例素材、课后练习和分层教学方案，由教师做最终判断。

**企业能力验证**：用独立完成程度、迁移表现和项目结果，补充简历和证书看不到的能力信息。

## 11｜这是一个可运行、可验证、可复用的教育 Agent

**模型**：DeepSeek 负责任务理解、工具选择和教学语言生成；不可用时显示降级。

**Agent Runtime**：观察、计划、行动、取证、重新规划、验证和停止。

**工具 / 知识库**：代码执行、Tree-sitter、数据流分析、测试、754 道结构化练习和分级可信内容。

**数据处理与部署**：React Web App + Gateway + PostgreSQL + Redis + 受限代码运行服务。

**数据与教育边界**：使用公开数据、模拟数据或经授权脱敏数据；AI不替代教师、学校或专业机构的最终教育评价。

**开放 / 复用**：可运行代码、Agent工具合同、教学事件模型、示例数据和技术文档。

## 12｜先让一个基础薄弱的人学会，再把能力变成可信结果

**现在**：完成可运行的个性化算法学习和教学辅助 Agent Beta，打通诊断、学习、代码运行、Mentor、迁移和成长回放。

**复赛**：接入题目截图、报错截图、手写推导和语音思路，完成多模态学习现场；启动首批教师裁决和真实学习实验。

**长期**：从算法过桥课程扩展到 AI 技术人才培养、项目实训与能力验证。

**愿景**：中国起步、面向全球的 AI 技术人才培养与能力验证平台。

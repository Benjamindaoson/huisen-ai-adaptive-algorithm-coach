# 汇森AI 算法教练｜GOAI 初赛路演内容

## 01｜封面

**汇森AI 算法教练**

不是帮你做出这道题，  
而是让你独立做出下一道题。

AI+教育｜职业教育 / 编程教育 Agent｜可运行 Demo

## 02｜我们解决的不是“缺题”，而是“不会独立迁移”

零基础、非科班学习者常遇到三次断裂：

- **听懂了，却写不出来**：知识没有变成可执行动作。
- **这道会了，下一道又不会**：记住答案，没有形成迁移能力。
- **练了很多，不知道下一步**：题量增加，薄弱点仍不可解释。

现有题库擅长提供题目和答案；通用聊天助手擅长生成解释。  
但学习真正需要的是：基于过程证据，持续缩小任务并验证“能否独立完成”。

## 03｜目标用户与第一个高频场景

**第一个目标用户**

想通过算法笔试、但缺少计算机基础和自学方法的学习者。

**第一个任务闭环**

用 10 分钟完成一个算法动作：

诊断起点 → 通俗微课 → 状态预测 → 局部编码 → 代码运行 → 最小提示 → 陌生迁移 → 延迟复测

**边界**

华为 OD 只是现有内容入口；产品能力面向可扩展的算法学习与工程实训。

## 04｜用户首分钟就能感到 AI 正在理解自己

AI 不先给一个模糊总分，而是展示：

- 我观察到的三个入口动作；
- 目前最可能的卡点；
- 为什么今天安排这段训练；
- 还需要什么证据才能改变计划。

结果是一张可执行的 10 分钟训练卡，而不是一串题目推荐。

## 05｜沉浸式 AI 训练舱：学中练，练中学

一个训练单元只保留五个动作：

1. **听懂**：生活语言建立直觉；
2. **看见**：把变量与程序状态可视化；
3. **预测**：运行前先说出下一步；
4. **动手**：只写当前最关键的一小段；
5. **独立迁移**：换表面、保技能，验证是否真的会用。

一次即时迁移只形成短期证据；系统不会把它包装成长期掌握。

## 06｜真正的 Mentor：先取证，再教学

每次 Mentor 行为绑定同一次提交快照：

- 当前代码、语言、输入、运行结果；
- AST / 控制与数据依赖等代码结构证据；
- 可信题库与知识索引检索结果；
- 模型决策、工具调用、代码差异、成本与停止原因。

模型可以主动选工具、重新规划、承认证据不足；  
判题事实由隔离运行服务决定，模型不能把猜测伪装成结果。

## 07｜苏格拉底式闭环：最小提示，不泄题

Mentor 的默认顺序不是“生成答案”，而是：

观察 → 提出假设 → 调用工具取证 → 让学生预测状态 → 给最小提示 → 观察修改 → 再次验证 → 安排迁移

关键产品规则：

- 运行前不启动上下文诊断；
- 参考答案后置，考试模式隐藏；
- 提示只推进当前一步；
- 迁移题通过后仍安排延迟复测。

## 08｜从做题走向真实工程能力

项目实训把算法动作放入模拟仓库：

需求理解 → 缺陷定位 → 制定计划 → 实施修改 → 自动化测试 → 工程复盘

平台分别记录：

- 任务是否通过；
- 使用过多少次提示；
- 能否解释修改依据；
- 是否能在新任务中独立迁移。

完成结果与独立程度不混成一个总分。

## 09｜可运行、可验证、可复现的技术路线

**Web App**：React + Vite  
**服务端**：Gateway + PostgreSQL 学习数据  
**代码执行**：受限运行服务 / Judge0 接口  
**Mentor Runtime**：DeepSeek + 工具编排 + 可追溯事件  
**知识增强**：题目、知识、参考解、错误模式分级索引  
**质量门禁**：教师盲评、模型校准、回归测试

本地验证：732 项测试通过，前后端类型检查和生产构建通过；754 道题已接入内容索引。

## 10｜安全、数据与教育边界

- 学习数据来自公开、模拟或经授权脱敏的数据；
- 不在前端保存模型密钥；运行服务设置资源与输出限制；
- 参考答案、隐藏测试与 Mentor 上下文分离；
- 内容显示来源与可信等级；
- AI 反馈仅用于形成性学习指导，不替代教师、学校、企业或专业机构的最终评价；
- 支持学习数据导出与导入。

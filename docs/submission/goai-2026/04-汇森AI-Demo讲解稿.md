# 汇森AI 4分钟Demo讲解稿

目标时长：240秒  
画面规格：1920×1080，明亮主题  
核心口号：不是帮你做出这道题，而是让你独立做出下一道题。

## 演示准备

- Web：`http://127.0.0.1:4174/`
- Gateway：`http://127.0.0.1:8787/healthz`
- 浏览器使用比赛专用新档案，不包含个人学习数据。
- 演示内容使用“数组遍历”自建微课和有界模拟学习输入。
- 题目工作台镜头只展示学习者代码、公开运行结果和Mentor工具时间线，不展示来源待确认的完整题面或参考答案。
- 预先验证网络、DeepSeek余额和Judge0；即使模型不可用，也保留一次真实的降级镜头说明系统不会伪造Agent活动。

## 镜头1：这不是另一套题库（0:00–0:22）

**页面**：今日训练首页。  
**操作**：停留在学习目标和“AI入门诊断”入口。  
**画面结论**：用户首先看到训练目标，而不是题目列表。

**旁白**：

> 很多算法基础薄弱的学习者并不缺题。他真正缺少的是：有人能看懂他卡在哪里，解释为什么，并验证他下一次能否独立完成。汇森AI不是替用户做题，而是帮助他独立做出下一道题。

**字幕**：`问题不是没有答案，而是没有形成独立能力。`

## 镜头2：AI先用证据认识学习者（0:22–0:55）

**页面**：AI入门诊断。  
**操作**：完成三个有界动作：预测程序状态、选择实现思路、判断建模方式。  
**画面结论**：诊断结果显示三条实际观察、推断、置信边界和推荐原因。

**旁白**：

> 新用户先完成三个一分钟内可以回答的小动作。系统不会凭一句“我是零基础”直接打分，而是把每个选择记录为可解释证据。它告诉学习者观察到了什么、为什么从这里开始，以及哪些结论仍然需要后续练习验证。

**字幕**：`目标 + 三个诊断动作 → 可解释的训练入口`

## 镜头3：训练不从答案开始（0:55–1:28）

**页面**：训练舱 `#/training/starter-array-traversal`。  
**操作**：依次展示水果类比、数组状态帧、第一次循环预测和局部补全代码。  
**画面结论**：一节课同时包含解释、预测、状态变化和动手编码。

**旁白**：

> 推荐的第一节训练不是一篇长文章。数组遍历被解释成“把一篮水果逐个拿出来”：每一轮只处理一个值。学习者先预测第一次循环拿到什么，再观察变量状态，最后只补全一小段代码。系统用练中学、学中练的方式降低第一次理解门槛。

**字幕**：`通俗解释 → 状态预测 → 局部编码`

## 镜头4：提交一个真实错误（1:28–1:55）

**页面**：题目工作台，聚焦代码编辑器和公开运行结果。  
**操作**：运行预设的边界错误代码；公开样例出现错误或不一致结果。  
**画面结论**：确定性运行结果先于AI结论出现。

**旁白**：

> 接下来学习者进入真实代码工作台。这段代码在循环边界上犯了错误。判题和运行结果由确定性执行系统给出，模型无权把错误说成通过，也不能修改运行证据。

**字幕**：`判题结果是权威证据，模型不能改写。`

## 镜头5：Mentor不是聊天框（1:55–2:45）

**页面**：编辑器旁的Mentor时间线。  
**操作**：启动诊断；停留在实际工具调用、证据、当前假设和证据缺口。  
**画面结论**：可见语法分析、控制流/数据流、知识检索和测试动作。

**旁白**：

> Mentor不是等待提问的聊天框。它读取这次不可变提交快照，自主选择语法树、控制流、数据流、知识检索和运行测试工具。每一步工具结果都会进入下一轮规划。证据不足时，它必须说还缺什么；动作非法、模型失败或服务断开时，界面会明确显示拒绝或降级，而不是用预设文字冒充Agent。

**字幕**：`观察 → 选择工具 → 读取结果 → 重新规划`

## 镜头6：只给最小必要帮助（2:45–3:15）

**页面**：Mentor预测问题与最小提示。  
**操作**：回答程序状态预测；根据提示只修改循环边界的一处代码。  
**画面结论**：没有展示完整参考答案，也没有自动写入代码。

**旁白**：

> 系统先让学习者预测最后一轮访问的位置，根据回答判断是否混淆了“元素数量”和“最后索引”。它只建议检查一个边界，不直接展示完整解法，也不替用户修改代码。

**字幕**：`最小提示保留了学习者的思考责任。`

## 镜头7：修改必须被验证（3:15–3:38）

**页面**：代码编辑器、运行结果和Mentor验证回执。  
**操作**：重新运行修改后的代码；展示通过结果和代码差异。  
**画面结论**：Mentor明确说明原假设是否被新证据支持。

**旁白**：

> 修改后系统重新运行测试，并对比本次代码差异。只有新的执行证据支持原诊断，Mentor才结束这一轮。一次通过仍然只是当前任务成功，不会直接变成“已经掌握”。

**字幕**：`学生修改 → 自动重测 → 结论验证`

## 镜头8：真正的目标是下一道题（3:38–4:00）

**页面**：迁移任务入口与成长回放。  
**操作**：展示同技能不同表面的迁移任务，以及“为什么练、学会什么、仍缺什么、下一步为何如此”。  
**画面结论**：Agent将一次做题变成下一次训练安排。

**旁白**：

> 最后，系统安排一项表面不同、底层技能相同的迁移挑战。无提示独立通过才形成更强的掌握证据。成长回放告诉学习者今天为什么练、目前有哪些证据、还不能确认什么，以及下一步为什么这样安排。这就是汇森AI：不是帮你做出这道题，而是让你独立做出下一道题。

**字幕**：`独立迁移，才是更可信的掌握证据。`

## 失败与替代镜头

- **DeepSeek不可用**：保留界面“服务未连接/本地静态回退·未验证”的真实状态，并旁白说明降级边界；不得把本地规则称为模型诊断。
- **Judge0不可用**：展示“无法连接运行服务”，转用已保存的公开运行证据截图解释，不伪造现场通过。
- **账号未登录**：使用浏览器本地学习档案，明确不声称云端同步。
- **时间线过长**：只滚动到“工具→证据→最小提示→验证”四个关键节点，不剪接成不存在的连续调用。

## 录制验收

- 总时长220–260秒；
- 画面中不出现密钥、邮箱、手机号、文件绝对路径或来源不明完整题面；
- 每个字幕至少停留2秒；
- 鼠标动作平稳，无无关标签页和通知；
- PPT、视频和运行说明中的产品名、数字和能力边界一致。

# 汇森AI 产品 Demo 讲解稿

成片时长：3分19秒

画面规格：1920×1080，H.264 + AAC

产品定位：AI+教育｜面向个性化学习与教学辅助的教育 Agent。

核心表达：不是替学生做出这道题，而是让他独立做出下一道题。

## 镜头1｜0:00-0:16｜第一秒进入产品

**画面**：今日任务完整界面，产品从第一帧出现。

**旁白**：这是汇森AI，一款面向个性化学习与教学辅助的教育Agent。它服务于非科班和基础薄弱的学习者：课程听懂了，代码却写不出；参考答案看懂了，换一道题又不会。我们不再给他更多答案，而是先看懂他究竟卡在哪里。

**字幕**：先看懂你为什么不会。

## 镜头2｜0:16-0:33｜个性化学习规划

**画面**：继续停留在今日任务，突出任务目标、推荐原因、预计时间和完成收益。

**旁白**：用户进入今日任务，AI会结合学习目标、知识基础、练习表现和可用时间，生成阶段性学习计划，并解释为什么今天先学这个、预计需要多久、完成后能获得什么。新的运行、提示依赖和复测结果，会继续动态调整学习路径。

**字幕**：目标、基础、表现与时间 → 动态学习路径。

## 镜头3｜0:33-0:50｜沉浸式 AI 训练舱

**画面**：微课、程序状态预测、局部编码和迁移挑战同时进入镜头。

**旁白**：点击开始后进入沉浸式训练舱。系统先用生活语言讲清算法直觉，再把变量和程序状态可视化。学生在运行前先做预测，只补当前最关键的一小段代码。每一步都很短，但从理解、建模到实现是连起来的。

**字幕**：通俗微课 → 状态预测 → 局部编码。

## 镜头4｜0:50-1:06｜学生先运行，Mentor 再介入

**画面**：真实题目工作台，左侧任务，右侧代码和运行区。

**旁白**：进入代码工作台，左边是任务与教学内容，右边是可以直接运行的代码。学生保留修改权，系统不自动替他写完。运行之后才进入辅导阶段，这让导师分析的始终是一次真实提交，而不是脱离任务的泛聊天。

**字幕**：学生先运行，Mentor 再介入。

## 镜头5｜1:06-1:25｜作业辅导 Agent

**画面**：Mentor 时间线，依次出现计划、工具、证据、最小提示和下一步。

**旁白**：Mentor读取当前任务、不可变代码快照、运行结果和代码差异，先判断证据够不够，再自主选择代码执行、结构分析、测试和知识检索工具。工具返回后它会重新规划，只给最小必要提示，并明确告诉学生：观察到了什么、最可能错在哪里、还缺什么证据、下一步只改哪里。

**字幕**：任务理解 → 工具调用 → 重新规划 → 最小提示。

## 镜头6｜1:25-1:45｜Agent 不是聊天窗口

**画面**：工具和证据面板，显示工具调用、测试结果、代码差异和停止原因。

**旁白**：每个结论都绑定工具调用和可核对证据。模型不能改变编译、运行和判题结果；证据不足时必须承认不知道；DeepSeek不可用时，界面显示真实降级状态。这里的Agent能力来自任务理解、流程编排、工具调用、知识增强和主动停止，而不是给聊天窗口换一个名字。

**字幕**：证据、工具、代码差异与停止原因都可核对。

## 镜头7｜1:45-2:02｜从做对到掌握

**画面**：迁移任务和成长回放，展示提示隐藏、重新提交和延迟复测。

**旁白**：学生根据最小提示自己修改并重新运行。通过以后，系统不会马上宣布掌握，而是安排表面不同、底层技能相同的迁移任务。只有在较少帮助下再次独立完成，才形成更强的掌握证据；之后还会进入延迟复测。

**字幕**：自动验证 → 陌生迁移 → 延迟复测。

## 镜头8｜2:02-2:18｜学情诊断 Agent

**画面**：能力模型和成长回放，突出五阶段、提示依赖与下一步。

**旁白**：成长回放把一次学习拆成理解、建模、实现、调试和验证。学情诊断分别展示任务成功、独立完成、提示依赖、迁移表现和遗忘风险，生成学情分析报告、改进建议和下一步任务，而不是压成一个看不懂的总分。

**字幕**：薄弱点、提示依赖、迁移表现与改进建议。

## 镜头9｜2:18-2:37｜从代码练习走向项目实训

**画面**：项目实训页，展示需求、任务拆解、代码、测试与工程复盘。

**旁白**：学习不能停在算法题。作为职业教育和编程教育Agent，项目实训围绕岗位技能、代码练习和面试准备，提供任务拆解、过程指导、反馈评价和学习路线建议。学习者在模拟代码仓库里理解需求、定位缺陷、修改代码、执行测试并完成工程复盘。

**字幕**：任务拆解 → 过程指导 → 反馈评价 → 项目结果。

## 镜头10｜2:37-2:58｜技术路线、数据与边界

**画面**：Mentor 已验证工具卡片，保持产品界面，叠加部署与数据说明。

**旁白**：技术上，React Web App连接Gateway、PostgreSQL、Redis和隔离Judge0；Mentor通过受限工具接口使用DeepSeek，知识库区分候选、自动验证和人工可信内容。数据使用公开、模拟或经授权脱敏数据，支持导出删除，不替代教师、学校或专业机构的最终教育评价。

**字幕**：模型、工具、知识库、数据与部署边界。

## 镜头11｜2:58-3:19｜多模态路线与产品愿景

**画面**：回到今日任务，保持产品主界面并收束。

**旁白**：当前版本已经联合理解文字目标、代码、运行结果和学习行为。复赛将加入题目与报错截图、手写推导和语音思路，让AI能看、能听、能读代码；同时获得教师裁决和真实学习证据。汇森AI的原则始终不变：不是帮你做出这道题，而是让你独立做出下一道题。

**字幕**：能看、能听、能读代码，仍然把修改权留给学生。

## 演示边界

- 当前多模态图片和语音能力属于复赛实现计划，初赛材料不把它写成已上线功能。
- DeepSeek 不可用时，界面显示真实降级状态，不把本地规则称为模型诊断。
- Judge0 不可用时，显示连接失败或已保存的公开运行证据，不伪造现场通过。
- Demo 只使用自建或模拟学习输入，不展示密钥、个人信息或来源待确认的完整题面。

# 汇森AI 4分钟Demo讲解稿

成片时长：4分16秒

画面规格：1920×1080，H.264 + AAC

核心口号：不是帮你做出这道题，而是让你独立做出下一道题。

这份讲解稿与提交包中的 `03-汇森AI-产品演示.mp4` 一致。成片使用真实运行截图、中文旁白和画面字幕；没有剪接出不存在的 Agent 行为。

## 镜头1｜这不是另一套题库

**画面**：汇森AI 封面。

**旁白**：很多算法基础薄弱的学习者并不缺题。他真正缺少的是，有人能看懂他卡在哪里，解释为什么，并验证他下一次能否独立完成。汇森AI不是替用户做题，而是帮助他独立做出下一道题。

**字幕**：问题不是没有答案，而是没有形成独立能力。

## 镜头2｜AI 先解释为什么今天这样练

**画面**：今日驾驶舱与入口诊断结果。

**旁白**：用户打开产品，首先看到的不是七百多道题，而是AI根据学习证据编排的今日训练。系统明确展示观察到的入口动作、目前最可能的卡点、为什么从这里开始，以及哪些判断还需要后续练习验证。它输出的是一张可执行的十分钟训练卡，而不是一个模糊总分。

**字幕**：目标 + 三个诊断动作 → 可解释训练入口。

## 镜头3｜把算法拆成真正能学会的五步

**画面**：数组遍历训练舱。

**旁白**：进入训练舱以后，算法被拆成五个连续动作。先用生活语言听懂，再看见变量和程序状态；运行前先做预测，然后只补全当前关键的一小段代码，最后换一个不同题面独立迁移。一次即时迁移只形成短期证据，系统不会把它包装成长期掌握。

**字幕**：通俗解释 → 状态预测 → 局部编码 → 陌生迁移。

## 镜头4｜运行前，Mentor 保持安静

**画面**：代码工作台与等待运行的学习导师。

**旁白**：进入代码工作台以后，左边是题目，右边是代码和测试面板。运行之前，Mentor不会抢答，也不会提前展示参考答案。学习者必须先写、先运行；确定性的执行结果出现以后，AI才获得开始诊断的资格。

**字幕**：先写、再运行，Mentor 才开始工作。

## 镜头5｜运行后，Mentor 开始真实工作

**画面**：DeepSeek 动态规划、提交绑定、状态预测与工具证据。

**旁白**：这一次真实运行生成了不可变提交编号。Mentor读取同一次代码、输入、语言和运行结果，自主选择代码结构分析、跨函数语义图和知识检索工具。每一步工具结果都会进入下一轮规划。当前证据只支持继续追问，所以它主动停在状态预测，而不是生成完整答案。判题事实由运行服务决定，模型不能把猜测伪装成结果。

**字幕**：观察 → 选工具 → 读取结果 → 重新规划 → 主动停止。

## 镜头6｜真正的目标是下一道题

**画面**：独立迁移与成长回放。

**旁白**：学生完成关键修改以后，系统会重新运行并核对新的证据。随后安排表面不同、底层技能相同的迁移任务。无提示独立通过以后，成长回放会说明今天完成了什么、还有什么不能确认，以及为什么之后仍然需要延迟复测。

**字幕**：学生修改 → 自动重测 → 独立迁移 → 延迟复测。

## 镜头7｜从算法动作走向工程现场

**画面**：项目实训与六阶段工程闭环。

**旁白**：汇森AI不准备永远停留在算法题。项目实训把能力带入模拟仓库，让学习者经历需求理解、缺陷定位、制定计划、实施修改、自动化测试和工程复盘。平台把任务是否通过、使用过多少提示、能否解释依据分别记录，避免AI代做制造虚假能力。

**字幕**：需求 → 定位 → 计划 → 修改 → 测试 → 复盘。

## 镜头8｜能力模型只接受可解释证据

**画面**：即时迁移证据、能力模型和持续导师。

**旁白**：能力模型只接受可解释事件。一次即时迁移可以记录为即时成功，但不能直接升级为长期掌握。持续导师会结合当前目标、任务证据、提示依赖和复测结果，告诉学习者下一步只做什么，以及为什么这样安排。

**字幕**：没有证据时，系统不会假装已经掌握。

## 镜头9｜不伪造满分，也是一种产品能力

**画面**：导师质量实验室与 0/100 真实教师金标。

**旁白**：我们也把尚未完成的地方直接展示出来。当前教师裁决金标仍然是零比一百，所以发布门禁保持红灯，系统禁止宣称导师质量已经被真实用户验证。下一阶段将用真实错误提交、教师盲评、陌生题独立通过率和七天延迟复测来证明学习效果。

**字幕**：0 / 100 真实教师金标：红灯就是诚实边界。

## 镜头10｜结束

**画面**：使命与口号。

**旁白**：这就是汇森AI算法教练。让更多普通人更容易学会，牢固掌握，并把能力真正应用到工作中。不是帮你做出这道题，而是让你独立做出下一道题。

**字幕**：不是帮你做出这道题，而是让你独立做出下一道题。

## 失败与替代镜头

- **DeepSeek不可用**：保留界面“服务未连接/本地静态回退·未验证”的真实状态，并旁白说明降级边界；不得把本地规则称为模型诊断。
- **Judge0不可用**：展示“无法连接运行服务”，转用已保存的公开运行证据截图解释，不伪造现场通过。
- **账号未登录**：使用浏览器本地学习档案，明确不声称云端同步。
- **时间线过长**：只滚动到“工具→证据→最小提示→验证”四个关键节点，不剪接成不存在的连续调用。

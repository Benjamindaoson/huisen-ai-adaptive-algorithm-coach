## 作品如何对应赛题

- **个性化学习规划 Agent**：根据学生目标、知识基础、练习表现和学习时间生成阶段性学习计划，并动态调整学习路径；
- **作业辅导 Agent**：提供分步骤提示、错因分析、知识点回顾和同类题训练，而非直接给出答案；
- **学情诊断 Agent**：根据练习记录和测试结果识别知识薄弱点，生成学情分析报告和改进建议；
- **职业教育 / 编程教育 Agent**：围绕岗位技能、项目实训、代码练习和面试准备，提供任务拆解、过程指导、反馈评价和学习路线建议。

# 汇森AI Agent能力与技术架构

## 一句话架构

汇森AI以一个证据驱动的Mentor Agent作为在线教学控制器：它理解当前学习任务，选择受限工具，读取真实结果，重新规划教学动作，并把经过验证的学习事件投影为下一步训练。

## 为什么是一个Agent

在线学习默认只有一个Mentor控制Agent。规划、诊断、提示、验证不是四个互相独立的聊天角色，而是同一教学目标下的连续状态。只有当权限、上下文或评测目标明显不同，系统才会把离线内容校验、教师审核等工作拆成独立流程。

这种设计避免了“多个名字、同一段提示词”的伪多Agent，也降低上下文污染和责任不清。

## Agent任务闭环

1. **任务输入**：学习目标、当前页面、公开题目信息、代码、公开运行结果和已有学习事件。
2. **意图与约束理解**：识别当前目标是理解、建模、实现、调试还是验证，并读取“不可直接泄题”等教学策略。
3. **计划生成**：决定还需要什么证据，以及下一步应调用什么工具。
4. **工具调用**：执行代码结构分析、可信内容检索、运行时探针、候选测试或学习者证据查询。
5. **重新规划**：把工具结果作为下一步输入；无效动作会被拒绝并允许纠正。
6. **教学交付**：提出一个状态预测问题、给出最小必要提示或说明证据不足。
7. **修改验证**：观察学习者修改、代码差异和新运行结果，验证原诊断是否成立。
8. **停止与迁移**：达到当前目标后主动停止，并安排不同表面的同技能迁移任务。

## 核心工具

### 1. 代码解析与结构证据

- Tree-sitter解析JavaScript、Python、Java和C++；
- 语法错误以证据返回，不被静默隐藏；
- 建立有界语言中立控制流和def-use摘要；
- 提取直接调用边、支配关系、到达定义和结构化路径风险。

这些结果用于形成“可能在哪里错、为什么值得检查”的假设，不替代编译器或正式判题。

### 2. 运行时探针与差分验证

- 只对诊断副本做有界插桩；
- 每个探针只暴露少量保守可见状态；
- 正式判题仍执行学习者原始源码；
- 候选测试必须有人工评审或多参考解共识，才能成为更高可信证据。

### 3. 可信知识检索

检索索引覆盖结构化题目、参考解、技能和典型误区。检索同时考虑中文字符/二元组、词法相关、技能相关、误区相关和可信等级。模型生成内容默认是未验证候选，不能与人工评审内容混为一谈。

### 4. 隔离代码执行

JavaScript、Python、Java和C++通过Judge0执行。Gateway对来源、请求大小、语言、CPU时间、墙钟时间、内存、进程和网络进行限制。模型不能直接执行任意系统命令，也不能修改Judge结果。

### 5. 学习者数字孪生

数字孪生按技能记录：

- 独立、辅助和迁移通过；
- 提示依赖和失败次数；
- 典型误区概率；
- 证据时间、置信度和遗忘半衰期；
- 可追溯事件引用。

学习状态由事件投影，不允许模型直接写入“已经掌握”。辅助通过贡献小于独立通过，迁移通过贡献更高。

## 上下文与记忆

- 每次Mentor分析绑定一次提交快照、运行结果和代码差异；
- 路由上下文按今日、课程、训练、题目、考试或项目实训隔离；
- 学习事件是追加式证据，普通按键等噪声不进入长期记忆；
- 浏览器离线记录通过持久化outbox同步，服务端使用幂等键和权威版本处理重试与冲突；
- PostgreSQL保存登录用户的权威学习历史和Mentor会话。

## 失败与安全边界

- 未知工具、额外参数、重复动作和越权请求会被拒绝；
- 模型输出不符合合同会回退到有界确定性教学动作；
- Provider失败、三次动作拒绝或步骤预算耗尽会显式停止；
- 证据不足时返回“还缺什么”，不伪造结论；
- DeepSeek不可用时界面显示真实降级状态；
- Hidden tests、参考源码、密钥和任意模型字段不会进入浏览器响应；
- AI只提供形成性反馈，不替代教师、学校、企业或专业机构最终评价。

## 技术栈

| 层级 | 实现 |
|---|---|
| Web产品 | React 19、TypeScript、Vite、Monaco Editor |
| Gateway | Node.js 24、Fastify、结构化API合同 |
| Agent | DeepSeek工具调用、最多8步observe/act循环、PostgreSQL会话存储 |
| 代码智能 | Tree-sitter、CFG、def-use、支配关系、到达定义、运行时探针 |
| 知识增强 | 754道结构化练习索引、技能与误区检索、可信等级 |
| 执行 | Judge0、PostgreSQL、Redis、Docker网络与资源限制 |
| 学习状态 | 可解释教学事件、数字孪生、迁移与延迟复测投影 |
| 数据控制 | 本地备份、账号同步、导出、删除、冲突恢复 |

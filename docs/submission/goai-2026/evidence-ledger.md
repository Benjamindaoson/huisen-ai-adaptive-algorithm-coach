## 可证明的产品事实

### 产品与内容

- 产品形态：React 19 + TypeScript + Vite 单页Web App。
- 当前结构化题目索引：754道。
- 用户主流程：AI入门诊断 → 个性化任务 → 训练舱 → 代码运行 → Mentor诊断 → 最小提示 → 修改验证 → 同技能迁移 → 成长回放。
- 题目、课程、考试、项目实训、成长回放和信任与数据页面均已有可访问路由。

### Mentor Agent

- 在线学习默认只有一个控制Agent，不用多个角色名称伪装多Agent。
- Mentor最多执行8个observe/act步骤。
- 模型可从严格校验的工具集合中选择工具和参数，并根据工具结果重规划。
- 非法工具、额外参数、重复动作、超出预算和模型失败会被拒绝或显式降级。
- Timeline展示观察、假设、证据缺口、工具结果、教学动作和停止原因。
- API Key仅由Gateway读取，不进入浏览器构建变量。

### 代码智能与运行

- Tree-sitter覆盖JavaScript、Python、Java和C++语法解析。
- 可生成结构化控制流、def-use摘要、直接调用边、支配关系、到达定义和有界路径风险。
- 可对诊断副本运行有界状态探针；正式判题仍使用学习者原始源码。
- 本地Compose栈通过Judge0隔离执行四种主流语言，并配置CPU、墙钟、内存、进程和网络边界。
- 代码分析是教学诊断证据，不宣称为编译器级sound analysis。

### 学习者模型与教学闭环

- 数字孪生按技能保存证据、置信度、半衰期、失败次数、独立/辅助/迁移通过和提示依赖。
- 模型不能凭感觉直接修改掌握度；学习状态由可解释事件投影。
- 课程完成和参考答案阅读不直接构成掌握。
- 无辅助通过不同表面的同技能任务，才构成更强的迁移证据。
- 入门诊断、推荐原因、训练交接、补课回流和“我现在明白了”反思均绑定学习事件。

### 数据与平台

- Gateway使用Fastify，学习数据和Mentor会话可持久化至PostgreSQL。
- 当前本地健康检查：`mentor.storage=postgres`、`mentor.identity=permissive-local`、`mentor.model=deepseek-chat`。
- 浏览器支持本地备份导出/导入；登录模式支持服务端同步、导出和删除。
- 同步使用幂等事件、持久化outbox、服务端权威状态和冲突恢复。

# 汇森AI 技术白皮书\n\n**作品方向**：AI+教育｜面向个性化学习与教学辅助的教育 Agent\n**细分场景**：职业教育 / 编程教育\n**版本**：GOAI 初赛 Beta，2026-08-16\n\n## 1. 作品概要\n\n汇森AI服务于非科班、基础薄弱，或已经学过课程却仍然无法独立完成算法任务的学习者。目标用户的困难常常不是“没有内容”，而是学习过程在几个关键地方断掉了：课程讲完后不知道如何开始，参考答案看懂后换题又不会，练习失败后不知道究竟卡在理解、建模、实现还是调试。\n\n产品不以“更快生成答案”为目标，而是完成一段可验证的学习任务闭环：\n\n> 诊断 → 阶段性学习计划 → 通俗教学 → 状态预测 → 局部编码 → 代码取证 → 最小提示 → 学生修改 → 自动验证 → 迁移任务 → 延迟复测 → 学情分析报告与改进建议\n\n核心产品原则是：**不是替学生做出这道题，而是让他独立做出下一道题。**\n\n## 2. 个性化学习与教学任务闭环\n\n### 2.1 个性化学习规划 Agent\n\n系统根据学生目标、知识基础、练习表现和学习时间，生成阶段性学习计划，并随新的提交、提示依赖、迁移任务和延迟复测结果动态调整学习路径。界面同时显示“为什么是现在”和“什么新证据会改变安排”，避免将个性化伪装成不可解释的推荐。\n\n### 2.2 作业辅导 Agent\n\n面向编程练习提供分步骤提示、错因分析、知识点回顾和同类题训练，而非直接给出答案。教学动作按“听懂-看见-预测-动手-迁移”组织，学生在运行前需先预测程序状态，修改权始终保留在学生手中。\n\n### 2.3 学情诊断 Agent\n\n系统基于练习记录、测试结果和模拟学习数据识别知识薄弱点，生成学情分析报告和改进建议。诊断结果分开展示任务成功、独立完成、提示依赖、迁移表现和延迟保持，不将它们压缩成一个不透明总分。\n\n### 2.4 职业教育 / 编程教育 Agent\n\n项目实训围绕岗位技能、代码练习和面试准备，提供任务拆解、过程指导、反馈评价和学习路线建议。学习者在模拟代码仓库中理解需求、定位缺陷、修改代码、执行测试并完成工程复盘。\n\n### 2.5 教师备课辅助路线\n\n机构版将在人工审核的课程知识和班级学情上，辅助教师生成课程大纲、课堂活动、案例素材、板书结构、课后练习和分层教学方案。这部分属于后续迭代计划，输出必须由教师审核。\n\n## 3. Agent 架构\n\n### 3.1 为什么是一个持续工作的 Mentor\n\n在线学习默认只有一个 Mentor 控制 Agent。规划、诊断、提示、验证和迁移是同一教学目标下的连续状态，不拆成多个只有名字不同的聊天角色。离线内容校验、教师裁决和运维审核因权限与评测目标不同，作为独立后台流程运行。\n\n### 3.2 运行时状态机\n\nMentor Runtime 进行有界 observe-act 循环，每个动作都保存计划、工具调用、证据引用、代码差异、成本信息和停止原因。\n\n1. **任务理解**：读取目标、当前路由、任务、代码快照、运行结果和学习证据。\n2. **流程编排**：判断当前处于理解、建模、实现、调试或验证阶段，选择下一个教学动作。\n3. **工具调用**：模型只能从权限化 Tool Registry 中选择工具和参数，未知工具、额外参数和越权请求会被拒绝。\n4. **知识增强**：根据当前技能、错因候选和内容可信等级检索证据。\n5. **重新规划**：工具结果返回后重新选择下一步，而不是在开始时一次生成全部回答。\n6. **多轮交互**：通过状态预测、运行、追问、修改和再验证形成苏格拉底式教学闭环。\n7. **结果交付**：输出已观察事实、最可能问题、证据缺口、最小提示、验证结果和唯一下一步。\n8. **主动停止**：目标达成、证据不足、连续动作被拒绝、Provider 失败或步骤预算耗尽时显式停止。\n\n### 3.3 不可变提交绑定\n\n每次 Mentor 分析绑定一次不可变提交快照、语言、运行结果和代码差异。学生继续修改编辑器后，界面明确显示“导师正在分析哪次提交”。任何由 Agent 建议的代码变更都必须先形成审批请求，由学习者明确接受或拒绝，不直接改写编辑器。\n\n## 4. 模型与降级策略\n\n### 4.1 模型使用方式\n\n- 服务端通过 DeepSeek 兼容 API 调用模型。\n- 模型用于任务理解、工具选择、教学问题和自然语言反馈。\n- DeepSeek API Key 只保存在 Gateway 环境变量，不以 `VITE_` 前缀暴露给浏览器。\n- 模型不能绕过工具参数验证，不能修改 Judge 状态，不能读取隐藏测试正文或参考源码。\n\n### 4.2 降级和失败可见性\n\n当 Provider 未配置、超时、断路器开启或模型输出不符合合同时，系统进入有界确定性降级流程。前端必须显示“模型不可用 / 本地规则建议 / 证据不足”，不得把降级文本冒充实时模型分析。\n\n## 5. 工具接口\n\n| 工具 | 典型输入 | 结果交付 | 权限与失败边界 |\n|---|---|---|---|\n| `inspect_syntax` | 代码快照、语言、分析焦点 | AST、控制流节点、def-use、调用边和证据引用 | 有界结构证据，不冒充完整程序语义 |\n| `search_evidence` | 题目、技能、误区和可信等级 | 算法知识、典型错误、反例和内容来源 | 模型生成内容默认为未验证候选 |\n| `generate_counterexample` | 错因假设、公开输入、约束 | 有界候选输入和生成理由 | 候选反例必须经执行或人工验证 |\n| `verify_hypothesis` | 错因假设、候选测试、快照 | 支持、反驳或仍未验证的结果 | 必须引用实际执行或结构证据 |\n| `update_twin` | 可解释学习事件 | 候选学习者状态投影 | 模型不能直接写入“已掌握” |\n| `ask_learner` | 教学问题、预期概念、目标技能 | 一个状态预测或最小追问 | 禁止一次追问多个不相关问题 |\n| `finish` | 达成条件、停止原因 | 学情摘要、改进建议和下一步任务 | 未达成条件时不得宣称掌握 |\n\n代码运行通过独立的提交接口与 Judge0 执行，运行结果作为 Mentor 证据而非模型输出。\n\n## 6. 代码智能与隔离执行\n\n### 6.1 结构分析\n\n系统为 JavaScript、Python、Java 和 C++ 提供 Tree-sitter 解析，建立有界语言中立控制流、def-use、调用边和路径风险摘要。语法错误作为证据返回，不被静默隐藏。\n\n### 6.2 运行时插桩和差分验证\n\n运行时探针只对诊断副本做有界插桩，每个探针只暴露少量保守可见状态。正式判题执行学习者原始源码。差分测试用实际执行结果判断某个错因假设是否成立。\n\n### 6.3 受限代码执行\n\nJavaScript、Python、Java 和 C++ 代码由 Judge0 执行。Gateway 对来源、请求大小、语言、CPU 时间、墙钟时间、内存、进程数和网络访问做限制。隐藏用例、参考源码和服务器内部 Oracle 不返回浏览器。模型文字不能改写编译、运行或判题结果。\n\n## 7. 知识库与 RAG\n\n### 7.1 索引内容\n\n当前知识索引包含 754 道结构化算法与编程练习、算法技能、先修关系、典型错误、微课、参考解和学习事件。“754 道”只表示建立了结构化索引，不表示全部内容已经完成来源审核、人工金标或生产级隐藏判题。\n\n### 7.2 可信等级\n\n| 等级 | 含义 | 允许用途 |\n|---|---|---|\n| `candidate` | 模型生成或未完成来源复核 | 内部候选，不得用于正式掌握证据 |\n| `auto-validated` | 通过结构、技能引用、参考解执行和测试一致性检查 | 可用于辅助训练，界面必须标明等级 |\n| `human-verified` | 经教师或内容审核者复核 | 可用于正式教学和能力验证 |\n\n检索同时考虑中文字符与二元组、词法相关、技能相关、误区相关和可信等级。参考答案与隐藏测试与教学提示管道严格隔离。\n\n## 8. 学习者数字孪生与数据处理\n\n### 8.1 教学事件模型\n\n系统不保存无意义按键流和鼠标轨迹，只记录对教学有意义的结构化事件，如入口诊断、状态预测、代码运行、提示请求、修改、重测、迁移和延迟复测。学习过程被拆成理解、建模、实现、调试和验证五个阶段。\n\n### 8.2 掌握度投影\n\n数字孪生按技能记录独立完成、辅助完成、迁移通过、提示依赖、失败次数、典型误区、证据时间和遗忘速度。学习状态由确定性规则从事件投影，模型不允许直接写入“已经掌握”。辅助通过不直接提升掌握度，无提示迁移通过和延迟复测是更强证据。\n\n### 8.3 数据流\n\n1. 浏览器采集有界语义事件。\n2. 离线事件进入本地 outbox，恢复连接后幂等同步。\n3. Gateway 校验学习者主体、事件合同、幂等键和版本。\n4. PostgreSQL 保存权威学习历史、不可变提交、Mentor 会话和掌握度投影。\n5. 今日规划器根据新证据更新学习路径，并说明更改原因。\n\n## 9. 前后端、接口与部署方式\n\n### 9.1 系统组成\n\n- **Web App**：React 19 + TypeScript + Vite，提供今日任务、训练舱、题目工作台、考试、成长回放和项目实训。\n- **Gateway**：Node.js + Fastify，负责身份、学习数据、Mentor Runtime、判题调度、能力报告和 OpenAPI 合同。\n- **PostgreSQL**：账户、会话、学习档案、事件、不可变提交、Mentor 证据和迟延复测。\n- **Redis**：限流、队列与短期协调。\n- **Judge0**：四语言受限代码执行。\n- **对象存储**：用于生产类部署中的对象数据与备份接口。\n\n### 9.2 代表性接口\n\n- `/api/v1/auth/*`：注册、验证、会话、恢复和匿名数据归属。\n- `/api/v1/learners/:id/*`：学习档案、事件、状态、提交、导出和删除。\n- `/api/v1/submissions`：带幂等键的不可变提交与异步判题。\n- `/mentor-os/runs`：启动、恢复和控制 Mentor 运行。\n- `/mentor/sessions`：提交绑定的代码诊断会话。\n- `/api/v1/capabilities`：如实返回身份、学习存储、Judge 和 Mentor 的可用/降级状态。\n- `/api/v1/openapi.json`：可机器读取的前后端合同。\n\n### 9.3 部署方式\n\n本地完整栈通过 Docker Compose 启动 Gateway、PostgreSQL、Redis、对象存储和隔离 Judge0。浏览器前端独立启动 Vite 开发服务或构建为静态资产。生产模式缺少 PostgreSQL、强密钥、HTTPS Origin、安全 Cookie 或身份投递服务时，Gateway 拒绝启动。\n\n## 10. 数据授权、隐私保护、风险提示与行业边界\n\n### 10.1 数据授权与来源\n\n| 类别 | 示例 | 使用约束 |\n|---|---|---|\n| 团队自建内容 | 数组遍历微课、预测题、模拟错误代码 | 可用于 Demo，标明自建/模拟 |\n| 公开许可内容 | 开源文档、许可清晰的算法素材 | 记录来源、版本和许可证 |\n| 模拟学习数据 | 诊断选择、运行事件、迁移事件 | 明确称为模拟，不声称真实学习效果 |\n| 经授权脱敏数据 | 后续教师裁决与学习实验 | 明确告知、最小化采集、支持撤回和删除 |\n| 用户创建数据 | 代码草稿、学习目标、运行记录 | 用户可导出、删除，未经允许不用于额外目的 |\n| 来源待确认内容 | 未完成授权分级的题目 | 不进入核心演示和正式教学 |\n\n### 10.2 隐私保护\n\n- 长期学习事件默认不保存完整源码、任意 stdin/stdout 或自由文本答案。\n- 身份会话使用 HttpOnly、Secure、SameSite=Strict Cookie 与 CSRF 保护。\n- 密钥和数据库凭据仅位于服务端。\n- 登录用户可请求导出和删除学习数据；未登录用户可在浏览器内导出、导入和清除。\n- 不使用真实未成年人数据参加比赛演示。\n\n### 10.3 风险提示\n\n- 模型可能诊断错误，因此结论需与代码、运行和教师证据分层展示。\n- 公共 Judge0 不能作为生产 SLA；生产环境需独立计算资源和隔离运维。\n- 内容来源和许可需持续分级，未完成审核的内容不进入高可信库。\n- 个性化是基于有界学习证据的形成性建议，不是心理测评或人格判断。\n\n### 10.4 行业边界\n\n汇森AI是学习支持和教学辅助工具，不替代教师、学校、企业或专业机构的最终教育评价、正式考试结果和录用结论。产品不承诺就业结果，不把完成课程、查看答案或获得 AI 建议直接认定为掌握能力。\n\n## 11. 工程复现、质量与可观测性\n\n### 11.1 工程复现\n\n仓库提供运行入口、依赖锁文件、环境变量示例、Docker Compose、数据库迁移、OpenAPI 合同、样例输入输出和本地冒烟命令。关键校验包括单元测试、类型检查、前端生产构建、本地栈配置检查和服务冒烟。\n\n### 11.2 质量评测\n\nMentor 质量指标包括错误行定位、错因标签、证据充分率、最小提示有效率、直接泄题率和错误结论率。当前已有种子回归和真实错误提交导入流程，但正式教师裁决有效案例仍为 **0/100**。因此项目不宣称 Mentor 质量或学习效果已经被真实用户验证。\n\n### 11.3 可观测性\n\n- `/api/v1/capabilities` 对前端暴露真实服务能力和降级状态。\n- Mentor 时间线显示计划、工具、证据、假设、验证、成本和停止原因。\n- 判题提供队列、verdict 和运行指标的管理员路由，不返回隐藏用例正文。\n- 数据库迁移按校验和记录，已执行迁移不会被静默篡改。\n\n## 12. 开放复用与迭代计划\n\n### 12.1 可开放复用的资产\n\n- Mentor 工具合同和参数验证器。\n- 不可变提交、学习事件和掌握度投影数据模型。\n- 个性化计划说明、迁移验证和延迟复测参考实现。\n- Judge 隐私边界、Agent 权限策略和内容可信等级。\n- Docker Compose、OpenAPI、示例数据、运行说明和技术文档。\n\n### 12.2 迭代时间线\n\n**当前 Beta**\n\n打通个性化学习计划、训练舱、代码执行、Mentor、学情诊断、迁移任务、延迟复测、项目实训和本地全栈部署。\n\n**复赛阶段**\n\n1. 接入题目截图、报错截图、手写推导和语音思路，形成图片、语音、代码和运行现场的多模态理解。\n2. 建立教师盲评、仲裁和模型校准流程，获得至少 100 个有效教师裁决案例。\n3. 开展首批真实学习实验，测量 Mentor 建议后的独立修改通过率、陌生迁移通过率和 7 日复训率。\n\n**中期路线**\n\n从算法过桥课程扩展到 AI 应用工程、模型评测、数据工程和真实代码仓库项目；为学校和培训机构提供教师审核下的学情诊断和分层教学。\n\n**长期愿景**\n\n建立中国起步、面向全球的 AI 技术人才培养与能力验证平台，让学习者更容易学会、更牢固地掌握，并能在真实任务中创造价值。\n\n##

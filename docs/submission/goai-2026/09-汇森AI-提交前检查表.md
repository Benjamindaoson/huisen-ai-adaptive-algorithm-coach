# 汇森AI GOAI 初赛提交前检查表

## A. 初赛必交材料

- [ ] 作品简介不超过500字；
- [ ] 方案PPT可以正常打开；
- [ ] 方案PDF与PPT内容、页数和视觉一致；
- [ ] 报名人、队伍人数和成员信息已在官方系统确认；
- [ ] 提交入口、截止时间和最终格式已在官网再次核对。

## B. 强烈建议提交的验证材料

- [ ] 4分钟Demo视频可以从头播放；
- [ ] GitHub仓库或代码交付包可访问；
- [ ] README包含安装、配置、启动、主流程和失败处理；
- [ ] 至少一份真实运行日志或测试结果；
- [ ] 产品截图来自真实运行界面，不是设计稿冒充。

## C. Agent完整闭环

- [ ] 展示任务输入；
- [ ] 展示学习目标和约束理解；
- [ ] 展示计划或下一步；
- [ ] 展示至少一次真实工具调用；
- [ ] 展示工具结果如何影响下一步；
- [ ] 展示结构化、可操作的结果交付；
- [ ] 展示学习者修改后的自动验证；
- [ ] 展示证据不足或服务失败时的真实处理；
- [ ] 展示迁移任务或后续训练安排。

## D. 官方六项评分覆盖

- [ ] 行业场景价值：目标用户、真实痛点、价值和迁移潜力；
- [ ] Agent能力：理解、规划、多轮、工具、知识、记忆、交付和验证；
- [ ] 产品体验：入口清晰、流程自然、反馈及时、Demo稳定；
- [ ] 技术深度：架构、模型、工具、知识库、状态和复现；
- [ ] 安全合规：数据来源、隐私、教育边界、失败和可追溯；
- [ ] 开放复用：仓库、文档、示例配置、测试和复用计划。

## E. 数据与知识产权

- [ ] 核心Demo只使用团队自建、模拟或许可清晰内容；
- [ ] 未经确认的完整题面没有出现在PPT、视频和一页纸；
- [ ] 模拟学习事件明确标注为模拟；
- [ ] 不含真实未成年人或其他未经授权个人数据；
- [ ] 第三方模型、API、依赖、版本和用途已披露；
- [ ] 没有虚假Star、Fork、Issue、PR或用户数据；
- [ ] 没有把第三方品牌描述为合作、认证或背书。

## F. 秘密与隐私

- [ ] Git仓库不包含DeepSeek Key、数据库密码和签名秘密；
- [ ] 截图和视频不包含邮箱、手机号、验证码、绝对路径和系统通知；
- [ ] 浏览器标签页没有私人内容；
- [ ] 演示账号和模拟数据可在提交后安全保留；
- [ ] 数据导出和删除路径与材料描述一致。

## G. 诚实声明

- [ ] 没有宣称真实学习效果已验证；
- [ ] 没有宣称Mentor已有100个真实教师裁决案例；
- [ ] 没有宣称754道题全部具备完整隐藏判题；
- [ ] 没有把一个Mentor包装成多个自主Agent；
- [ ] 没有宣称生产SLA或100%上线就绪；
- [ ] 明确AI不替代教师、学校、企业或专业机构最终评价。

## H. 视觉与一致性

- [ ] 品牌统一为“汇森AI”，作品全称为“汇森AI 算法教练”；
- [ ] 核心口号完全一致；
- [ ] PPT固定10页，明亮主题，正文不低于16pt；
- [ ] 没有字体缺失、文字裁切、意外换行、重叠或黑块；
- [ ] 视频字幕、PPT数据、README和产品实际状态一致；
- [ ] 所有最终文件名有序、可打开、大小非零；
- [ ] 提交目录没有临时文件、构建脚本和无关日志。

## I. 最终运行

- [ ] `npm test`通过；
- [ ] `npm run lint`通过；
- [ ] `npm run typecheck`通过；
- [ ] `npm run build:web`通过；
- [ ] Gateway `/healthz`返回HTTP 200；
- [ ] 从新浏览器状态完整走通一次四分钟路径；
- [ ] 断开模型后验证降级文案真实；
- [ ] 完整观看最终视频并核对首尾帧和字幕。

# 汇森AI GOAI 暖色编辑式参赛材料重构设计

## 目标

将现有的 PPT、产品演示视频和技术说明重构为一套分工清晰、视觉统一、以产品演示为主的 GOAI 初赛提交材料。评委应在三分钟内理解汇森AI服务谁、解决什么问题、Agent 如何完成任务闭环、产品如何产生学习与商业价值。

## 核心主张

> 不是替学生做出这道题，而是让他独立做出下一道题。

产品从非科班、基础薄弱的算法学习者切入，通过个性化学习规划、作业辅导、学情诊断、迁移验证和项目实训，将“听懂了”变成“能独立完成”。

## 视觉系统

### 色彩

- 画布：暖米白 `#F4F1EA`，所有页面使用同一底色。
- 主文字：深墨蓝 `#142033`。
- 品牌主色：钴蓝 `#3659E3`。
- 完成与正向状态：青绿 `#20866F`。
- 次级文字：石板灰 `#667085`。
- 浅蓝面：`#E8EDFF`；浅青绿面：`#E6F3EE`。
- 不使用橙色，不使用整页黑底，不引入第三种高饱和强调色。

### 字体与层级

- 字体：`Noto Sans SC`，兼容回退为 `Microsoft YaHei UI`。
- 封面主标题：56-64 pt。
- 页标题：36-42 pt，一行完整呈现。
- 小标题：24-28 pt。
- 正文：18-22 pt，不得低于 16 pt。
- 注释和页脚：12-14 pt。
- 每页只有一个主结论，可见文字原则上不超过 70 个汉字。

### 构图

- 产品截图占页面面积 60%-75%，使用大尺寸、少边框、少阴影的编辑式构图。
- 不使用密集仪表盘卡片、按钮式文字、装饰性标签和小字表格。
- 相邻页面在大图、左右分屏、局部放大与简化流程之间变化，但边距、字体、颜色和页码系统保持一致。

## PPT 叙事

PPT 保持 12 页，以产品与商业说服为主：

1. 封面：核心主张与产品界面。
2. 用户困境：课程听懂了，面对任务仍然不会。
3. 产品方案：诊断、教学、练习、迁移、应用。
4. 个性化学习规划 Agent：首次诊断和今日任务。
5. 作业辅导 Agent：微课、预测、可视化、局部编码。
6. Mentor Agent：任务理解、流程编排、工具调用、知识增强、多轮交互、结果交付。
7. 学情诊断 Agent：薄弱点、学情报告和改进建议。
8. 迁移验证：在不同表面的任务中独立完成。
9. 职业教育 / 编程教育 Agent：岗位技能、项目实训和面试准备。
10. 商业价值：个人学习、教学辅助、企业能力验证。
11. 技术与边界摘要：模型、Agent Runtime、工具、知识库、数据、部署和责任边界。
12. 路线与愿景：算法过桥课、AI 技术人才培养、能力验证平台。

## 视频叙事

- 总时长：3 分 00 秒至 3 分 30 秒。
- 0:00-0:08：一句话说明真实用户困境，背景已经是产品。
- 0:08-0:35：个性化学习规划和今日任务。
- 0:35-1:05：沉浸式训练舱。
- 1:05-1:50：运行代码、Mentor 调用工具、定位错因、给出最小提示。
- 1:50-2:15：学生修改、自动验证和迁移任务。
- 2:15-2:38：成长回放与学习路径调整。
- 2:38-2:58：项目实训和商业价值。
- 2:58-3:20：在产品画面上叠加技术、数据边界、多模态规划和发展路线。

产品界面应占视频时长 85% 以上，不使用连续静态概念页，任何静态文字画面不超过 4 秒。

## 技术白皮书

新增 Markdown 和 PDF 两个版本，覆盖：

1. 目标用户、场景痛点和教学任务闭环。
2. 模型提供方、调用方式、降级与成本边界。
3. Agent Runtime、状态机、工具选择、重新规划和停止条件。
4. 工具接口的输入、输出、权限和失败处理。
5. 知识库、RAG、内容可信等级和隔离策略。
6. 题库、代码、学习事件的数据处理流程。
7. 隐私保护、授权、脱敏、风险提示和教育边界。
8. 前端、网关、数据库、代码执行容器的部署拓扑。
9. 日志、监控、测试、配置和工程复现方式。
10. 可开放复用的工具、数据合同、示例数据和技术文档。
11. 当前已实现、复赛计划和中长期路线。

## 诚信表达

- 已实现、可演示、模拟数据、计划实现必须使用不同标记。
- 不宣称学习效果已经被大规模真实用户验证。
- 不宣称已实现图像或语音输入；多模态作为复赛计划说明。
- 不将 Agent 结果作为教师、学校或专业机构的最终教育评价。

## 验收标准

- PPT 每页使用统一暖米白画布，无橙色，无整页黑底。
- PPT 正文不低于 16 pt，每页一个主结论，无意外换行、裁切和重叠。
- PPT 中产品相关页面不少于 8 页。
- 视频 8 秒内进入产品，产品画面时长占比不低于 85%。
- 视频展示至少一个“诊断-计划-工具-反馈-修改-验证-下一步”任务闭环。
- 白皮书完整回答比赛要求中的模型、Agent 架构、工具接口、知识库、数据处理、部署、授权、隐私、风险和开放复用。
- 所有交付物中的品牌名统一为“汇森AI”。

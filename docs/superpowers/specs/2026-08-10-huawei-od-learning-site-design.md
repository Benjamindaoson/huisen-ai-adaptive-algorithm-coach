# 华为 OD 学习站：第一版设计

## 目标与边界

把现有华为 OD 资料整理为可搜索、可阅读、可闯关和可运行代码的学习站。第一版面向个人及小范围分享：不要求登录，不做云同步、排行榜、支付、评论或完整线上判题。

用户进度只保存在浏览器本地，并可导出和导入 JSON 备份。题目运行必须支持 Java、Python、JavaScript 和 C++。

## 整理原则

1. `archive/original/` 保存现有 1,092 个源文件的原始副本和原目录层级；不在归档中修改内容。
2. 生成的题库不复制网页样式或脚本，只抽取可学习的正文：题干、输入输出、样例、思路、复杂度和参考代码。
3. 每道题有稳定 ID、来源路径、题名、分值、卷别/时段、语言、结构化正文和标签。
4. 正文哈希完全相同的题目归为重复组；只选一个默认展示版本，其余保留来源链接。题名相同但正文不同的资料不自动删除，标记为“待人工确认的变体”。
5. 资料中只有题名或“思路待更新”的 DOCX 保留为索引条目，不冒充完整题解。

## 项目结构

```text
archive/original/           原始资料，不可变
content/problems/           规范化题目 JSON（按 ID 分片）
content/index.json          搜索、标签、重复组与学习路径索引
scripts/                    资料抽取、校验、生成索引
web/                        Vite + React + TypeScript 静态前端
services/runner/            运行网关、Docker Compose 与运行服务说明
docs/                       设计、部署和资料维护说明
```

`web` 的构建产物是独立静态站；`services/runner` 是单独启动的代码执行服务。两者可分开部署。

## 学习体验

首页同时提供全文搜索、卷别/分值/题型/语言筛选和“本周路径”。路径以知识点组织：字符串与解析、数组与排序、栈队列、树图、动态规划、模拟与系统题；每个知识点由若干可完成关卡组成。

题目页采用数字书阅读布局：目录与元信息、题干、输入输出、样例、思路、复杂度、参考解答和编辑器。用户可将题目标记为未开始、进行中、已掌握、待复习或收藏；状态改变即时写入浏览器存储。导出文件包含模式版本、题目状态、笔记和更新时间；导入先校验结构，再合并或覆盖。

编辑器使用 Monaco。用户选择语言、编辑代码、填写标准输入并运行；结果显示标准输出、编译错误、运行错误、超时与资源受限状态。第一版不保存用户代码到服务器。

## 运行服务

采用 Judge0 CE，而不是浏览器端模拟器或 Piston。Judge0 CE 在 Docker Compose 中负责隔离编译和执行；轻量 Node 网关是前端唯一可访问的运行 API。

网关只接受 Java、Python、JavaScript、C++ 四种语言，并强制执行以下限制：源代码、输入和输出大小上限；约 2 秒运行时长；内存限制；单 IP 限流和单次请求并发限制。Judge0 和其数据库/Redis 不暴露到公网；网关只允许配置的静态站来源跨域访问。

第一版部署目标是单台 Linux 主机上的 Docker Compose。本地开发同样通过 Docker Compose 启动。公开部署前必须配置网关的允许来源、反向代理 HTTPS 与速率限制；静态站不能携带任何执行服务密钥。

## 数据流

```text
源资料 -> 抽取/清洗 -> 题目 JSON + 搜索索引 -> 静态站
用户操作 -> localStorage -> 导出/导入 JSON
编辑器代码 -> 运行网关 -> Judge0 CE -> 结果返回浏览器
```

## 验收标准

1. 原始资料可在 `archive/original/` 找回，数量与归档前一致。
2. 站点可按题名、正文关键词、卷别、分值和标签检索；重复题只显示一个默认版本并能查看来源。
3. 至少提供结构化题目详情、学习路径、状态标记、收藏、导入导出和移动端可用布局。
4. 四种允许语言均可运行一份最小程序，且超时、编译错误和运行错误能清晰呈现。
5. 前端可静态构建；执行服务可通过 Docker Compose 在本地启动；不把数据库、Redis 或 Judge0 直接暴露给浏览器。
6. 抽取、构建、类型检查、测试和本地运行验证均有可重复命令。

## 明确不做

- 用户账号与跨设备云同步
- 公开排行榜、讨论区和社交功能
- 复杂的隐藏测试判分与反作弊
- 未经人工复核的算法分类或题目合并
- 将现有辅导宣传材料当作官方招聘政策

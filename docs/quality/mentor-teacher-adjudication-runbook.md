# Mentor v2 教师金标裁决手册\n\n## 当前状态\n\n`npm run quality:mentor:queue` 会从已导入的真实错误提交生成 `quality/mentor-review-queue-v1.json`。当前队列有 200 条 CodeNet 提交，但 200 条全部标记为 `evidence-incomplete`：它们只有源代码、verdict 和元数据指针，没有可供教师审核的题面、失败输入/期望/实际结果、编译诊断或等价根因证据。\n\n队列还明确暴露两个覆盖缺口：当前数据只有 Python、Java 和 C++，缺 JavaScript；200 条提交的 `learnerBand` 都是 `unknown`。即使不加区分地标注 100 条，也不能通过完整覆盖门禁。\n\n## 不可越过的边界\n\n- `quality/provenance/mentor-cases.json` 只保存原始待裁决案例，不直接改写为金标。\n- `quality/mentor-adjudications-v1.json` 只保存具名教师裁决。每条记录必须绑定原始 `sourceHash`、教师身份声明、完整金标和已审核证据引用。\n- `quality/mentor-predictions-v2.json` 只保存待评估的 Mentor 预测。模型预测不能修改教师金标，A/B 偏好评审也不能自动晋级案例。\n- 本地 `role: teacher` 是明确责任声明，不是机构身份验证。正式教学实验上线前仍需接入真实教师身份系统。\n\n## 教师裁决记录\n\n输入文件是版本化 JSON：\n\n```json\n{\n  "version": 1,\n  "records": [\n    {\n      "caseId": "public-case-id",\n      "sourceHash": "64-character-sha256",\n      "reviewer": { "id": "teacher-001", "role": "teacher", "attested": true },\n      "completedAt": "2026-08-12T08:00:00.000Z",\n      "learnerBand": "beginner",\n      "reviewedEvidenceRefs": ["judge:failed-case:1"],\n      "expected": {\n        "errorFamily": "boundary",\n        "misconception": "off-by-one",\n        "lines": [12],\n        "hintIntent": "predict-boundary"\n      },\n      "prohibitedFragments": ["direct answer fragment"]\n    }\n  ]\n}\n```\n\n导入教师裁决和 Mentor 预测：\n\n```powershell\nnpm run quality:mentor:adjudications -- --input C:\path\to\teacher-records.json\nnpm run quality:mentor:predictions -- --input C:\path\to\mentor-predictions.json\n```\n\n生成队列并运行正式门禁：\n\n```powershell\nnpm run quality:mentor:queue\nnpm run quality:mentor\n```\n\n## 达到 100 条的实际路径\n\n1. 先补齐每条案例的题面和可定位根因的执行证据，再开放给教师。\n2. 额外采集 JavaScript 真实错误提交，并为所有案例提供可审核的 learner-band 来源。\n3. 教师盲审不少于 100 条；分歧案例由第二位教师仲裁，不由模型决定。\n4. 对同一快照运行待发布 Mentor，导入预测后运行 `npm run quality:mentor`。\n5. 只有样本量、覆盖和六项质量阈值全部通过，门禁才会变绿。\n\n

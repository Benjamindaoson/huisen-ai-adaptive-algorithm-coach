## Context\n\nThe existing quick recap is intentionally evidence-neutral: replay actions must not duplicate course completion or mastery evidence. That honesty should remain. The missing element is metacognition—after revisiting an explanation, the learner should actively identify which mental model is correct and see what the system learned from that response.\n\nThe existing `lesson-handoff-feedback` event already records bounded feedback for an evidence-bound recommendation and is ignored by mastery scoring. Reusing it with a fixed recap reason preserves the event contract while distinguishing recap closure from ordinary usefulness feedback.\n\n## Goals / Non-Goals\n\n**Goals:**\n\n- Make the end of recap visible and learner-owned.\n- Require an active distinction between the misconception and corrected explanation.\n- Persist at most one closure for the exact recommendation/source pair.\n- Keep closure explicitly neutral to mastery and transfer.\n\n**Non-Goals:**\n\n- Free-text reflection or model grading.\n- Marking a lesson, skill, or transfer as completed.\n- Replacing the later independent challenge.\n- Adding a new learning-event kind.\n\n## Decisions\n\n### Two bounded mental-model choices\n\nThe recap presents the lesson's known misconception and its corrected checkpoint explanation. The learner may only confirm closure after selecting the corrected model. Selecting the misconception keeps the loop open and offers a return to the human-language explanation.\n\n### Reuse bounded feedback with an explicit recap reason\n\nConfirmation emits one `lesson-handoff-feedback` signal with the return lesson ID, exact recommendation ID, `choiceId: helpful`, and `reason: recap-corrected-model:<sourceLessonId>`. A projection helper recognizes only this exact bounded shape.\n\n### Reflection is not achievement evidence\n\nThe UI states that closure records a change in understanding, not mastery. Existing mastery derivation ignores handoff feedback, and the new regression test proves this remains true. Transfer and delayed review remain the only stronger learning evidence.\n\n## Risks / Trade-offs\n\n- A bounded choice captures less nuance than free text, but it is safer, comparable, and does not require an unreliable generative grader.\n- A learner can select the correct statement without deep understanding. This is why the result remains metacognitive feedback only.\n- Reusing handoff feedback makes analytics depend on the fixed reason prefix; the projection helper centralizes that contract.\n\n

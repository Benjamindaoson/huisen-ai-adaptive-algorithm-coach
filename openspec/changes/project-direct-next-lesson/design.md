# Design\n\n## Single authority\n\n`deriveLessonProgress(events)` determines locked, available, started, checkpoint-passed, and completed states. `nextFoundationLesson(...)` selects the first started/checkpoint/available lesson. The post-transfer action SHALL consume these functions instead of implementing another ranking.\n\n## Action\n\nWhen immediate transfer is complete and a next foundation lesson exists, project:\n\n- state: `continue-foundation`\n- label: `继续下一课：<lesson.title>`\n- route: `#/learn/<lesson.id>`\n- evidence: the immediate-transfer event plus relevant lesson-progress evidence\n\nWhen no next lesson exists, keep `选择下一项训练 → #/paths`.\n\n## Scope\n\nThis is deterministic curriculum navigation, not an AI mastery claim. It reduces decision cost while retaining the map as an exploration surface.\n\n

## ADDED Requirements\n\n### Requirement: Empty learning evidence has one actionable beginning\nWhen a learner has no mastery evidence, the system SHALL explain that a first activity establishes a baseline and SHALL offer one visible action that opens a runnable learning activity or the first unlocked lesson.\n\n#### Scenario: Runnable baseline problem is available\n- **WHEN** the Insights page receives an empty mastery collection and a baseline action callback\n- **THEN** it SHALL render a button labelled "开始第一个练习" and invoke the callback when selected.\n\n#### Scenario: No runnable baseline problem is available\n- **WHEN** the Insights page receives an empty mastery collection without a baseline action callback\n- **THEN** it SHALL render a link to the learning center rather than a non-functional control.\n\n### Requirement: Daily page preserves one primary action\nThe Today page SHALL present the current recommended task as the first actionable content and SHALL label its action with the learner outcome rather than internal orchestration language.\n\n#### Scenario: A recommended task exists\n- **WHEN** the daily plan has a primary item\n- **THEN** the page SHALL expose one primary button that opens that item before optional planning evidence.\n\n

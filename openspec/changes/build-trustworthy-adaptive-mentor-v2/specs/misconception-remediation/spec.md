## ADDED Requirements\n\n### Requirement: Evidence-bounded misconception classification\nThe system SHALL classify only a bounded set of misconceptions and SHALL attach confidence, evidence references, and an authority level to each classification.\n\n#### Scenario: Compiler error supports input misconception\n- **WHEN** a failed attempt includes compiler or runtime evidence that matches a known input-parsing failure\n- **THEN** the system SHALL return the mapped misconception and the evidence that supports it\n\n#### Scenario: Evidence is insufficient\n- **WHEN** no compiler, runtime, or failed-case evidence supports a known misconception\n- **THEN** the system SHALL return an unknown or low-confidence learning route and SHALL NOT claim a confirmed root cause\n\n### Requirement: Smallest relevant remediation\nThe problem workspace SHALL route a learner with a supported misconception to the smallest incomplete prerequisite lesson.\n\n#### Scenario: Prerequisite is incomplete\n- **WHEN** the mapped lesson has an incomplete prerequisite\n- **THEN** remediation SHALL route to the earliest incomplete prerequisite and explain both the observed evidence and the route\n\n

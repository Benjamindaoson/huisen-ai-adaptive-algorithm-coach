# Change: Project a coherent post-transfer action\n\n## Why\n\nAfter a learner passes the new immediate transfer, the training cabin acknowledges success but Insights can still restart entrance diagnosis. The system must prefer stronger completion evidence over older or absent onboarding evidence.\n\n## What Changes\n\n- Add a completion-aware projected action backed by the immediate-transfer event.\n- Show a bounded post-training result in Insights when mastery evidence is still absent.\n- Give Insights, Today, and Mentor the same next-training label and destination.\n\n## Impact\n\n- Affected specs: `projected-learning-action`\n- Affected code: projected action contract/tests, Insights page/tests, route contribution fallback\n\n

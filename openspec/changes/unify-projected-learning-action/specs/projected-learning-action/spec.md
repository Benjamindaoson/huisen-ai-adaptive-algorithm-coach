## ADDED Requirements\n\n### Requirement: Bridge journey has one projected next action\nThe system SHALL project a single next action from validated learning events, containing a state, visible label, typed destination, hash href, and evidence references.\n\n#### Scenario: Diagnosis has not started\n- **WHEN** no current bridge diagnostic event exists\n- **THEN** the action is `开始 3 分钟诊断` and targets Today\n\n#### Scenario: Diagnosis is incomplete\n- **WHEN** one or two current bridge diagnostic steps exist\n- **THEN** the action is `继续入口诊断` and targets Today\n\n#### Scenario: Training is ready but not started\n- **WHEN** diagnosis is complete and no matching training-start event exists\n- **THEN** the action is `开始 10 分钟训练` and targets the projected entry lesson\n\n#### Scenario: Matching training already started\n- **WHEN** diagnosis is complete and a matching training-start event exists\n- **THEN** the action is `继续 10 分钟训练` and targets that same projected entry lesson\n\n### Requirement: Learner and Mentor surfaces share the projection\nBridgeEntryDiagnosis, Insights, and the local Mentor fallback SHALL consume the same projected label and destination for the same event history.\n\n#### Scenario: Insights resumes a started bridge lesson\n- **WHEN** Insights renders completed diagnosis plus matching training-start evidence without a runtime checkpoint\n- **THEN** the page CTA and Mentor fallback both say `继续 10 分钟训练`, and the CTA targets the same lesson in the projected action\n\n### Requirement: Runtime and non-bridge behavior is preserved\nThe system SHALL keep recovered Mentor checkpoints higher priority and SHALL preserve existing actions for non-bridge routes.\n\n#### Scenario: Deep Mentor has a checkpoint\n- **WHEN** a route-scoped runtime checkpoint exists\n- **THEN** the dock displays that checkpoint action instead of the local projected fallback\n\n#### Scenario: Review route is active\n- **WHEN** the current route is Review\n- **THEN** the existing review action remains unchanged\n\n

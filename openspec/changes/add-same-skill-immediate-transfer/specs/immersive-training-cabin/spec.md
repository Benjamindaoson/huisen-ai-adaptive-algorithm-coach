## MODIFIED Requirements\n\n### Requirement: The cabin SHALL teach through an ordered, observable learning loop\n\nThe system SHALL present explain, observe, predict, constrained build, and immediate transfer stages in that order. The first beginner transfer SHALL require only the skill taught by the current lesson, SHALL use a different surface form, and SHALL execute learner code outside the browser page process before completion is recorded.\n\n#### Scenario: Beginner reaches the first array transfer\n\n- **WHEN** a learner completes explain, observe, predict, and build for array traversal\n- **THEN** the cabin presents a new everyday traversal task that does not require interval merging, sorting, hashing, or another unintroduced skill\n\n#### Scenario: Transfer code is evaluated\n\n- **WHEN** the learner runs the immediate transfer\n- **THEN** the private runner executes at least two distinct cases and the stage advances only if every case has the expected output\n\n#### Scenario: Execution is unavailable or incorrect\n\n- **WHEN** the runner is unavailable or any case fails\n- **THEN** the cabin shows the bounded failure evidence, preserves progress, and does not record transfer completion\n\n### Requirement: The cabin SHALL expose an evidence-bound growth replay\n\nThe system SHALL distinguish immediate transfer-stage evidence from independently accepted real-problem mastery and delayed retention evidence.\n\n#### Scenario: Immediate transfer passes\n\n- **WHEN** every immediate-transfer case passes\n- **THEN** the replay may state that immediate transfer passed but SHALL state that long-term retention remains unverified and SHALL NOT create or imply a `lesson-transfer-passed` receipt\n\n

# Change: Add a same-skill immediate transfer\n\n## Why\n\nThe first array-traversal lesson currently hands a beginner to an interval-merging OD problem. The destination adds input parsing, sorting, and interval reasoning that the lesson did not teach, so the step labeled “independent transfer” is not a valid test of the taught operation.\n\n## What Changes\n\n- Add one trusted, executable immediate-transfer challenge for the first array-traversal lesson.\n- Execute learner Python in the existing private runner against two distinct cases.\n- Advance only when every case passes; report wrong output and runner unavailability honestly.\n- Record immediate transfer separately from real-problem mastery and delayed retention.\n- End the short lesson with a visible growth-replay action instead of silently opening an advanced OD problem.\n\n## Impact\n\n- Affected specs: `immersive-training-cabin`\n- Affected code: training transfer contracts, runner-backed evaluation, training cabin UI/tests, growth replay copy\n- Preserved systems: 754-problem catalog, normal problem workspace, hidden/reference-answer isolation, durable mastery evidence\n\n
